## Project Overview

**Name:** Workflow Orchestration Queue (OS-APOW)  
**Type:** Python FastAPI Application  
**Purpose:** Distributed task queue using GitHub Issues as backing store

## Key Components

### 1. Notifier Service (`src/notifier_service.py`)
- FastAPI application
- Receives GitHub webhooks at `/webhook/github`
- Creates work items in GitHub Issues
- Health check at `/health`

### 2. Sentinel Service (`src/orchestrator_sentinel.py`)
- Background daemon
- Polls GitHub Issues for queued items
- Processes tasks with concurrency limits
- Updates issue labels on completion

### 3. GitHub Queue (`src/github_client/github_queue.py`)
- GitHub Issues API wrapper
- Async operations with httpx
- CRUD operations for issues
- Label management

### 4. Models (`src/models/work_item.py`)
- `WorkItem`: Main task model
- `TaskType`: Enum for task types
- `WorkItemStatus`: Enum for statuses
- `WorkItemCreate`, `WorkItemUpdate`: DTOs

## Environment Variables

### Required for Both Services
- `*_GITHUB_TOKEN`: GitHub PAT with repo permissions
- `*_GITHUB_ORG`: Organization/user name
- `*_GITHUB_REPO`: Repository name

### Sentinel-Specific
- `SENTINEL_POLL_INTERVAL_SECONDS`: Polling interval (default: 60)
- `SENTINEL_MAX_CONCURRENT_TASKS`: Concurrency limit (default: 5)

## Common Commands
